# MAG collaboration adaptation NC v2

本轮是修复既有 MAG 协作骨干并检验 typed same/cross value（V）与保留自身语义的非线性融合（F）的 Movies、Grocery、Reddit-S train/validation 原型。只使用 split seed42 和冻结 20 类 Macro-F1 schema。没有测试集任务头前向/指标/选择，没有真实 LP，也没有 Toys 或 ele-fashion 正式训练。三个开发图的 validation 已在既往工作中被使用；seeds 只作描述性比较，不作显著性宣称。

- 修复复验 R：calibration 36/36，confirmation 18/18。
- 组合/对照 S：calibration 108/108，confirmation 54/54。
- 所有 attempt 的状态计数：`{"R_calibration_success": 36, "R_confirmation_success": 18, "S_calibration_success": 108, "S_confirmation_success": 54}`。重试单独登记；以下估计每个格只取最近一次成功 attempt。
- 全矩阵按照冻结规则执行；seed72校准不并入S确认均值。U 只用于本阶段预先声明的开发选择，Acc 与 Macro-F1 仍分别报告。

## 主要结果解读

- **R 修复复验**：相对 v1 同 seed，R-M0 在 Movies 的 val Acc/F1 平均变化为 +0.23/+3.61 pp，在 Grocery 为 −0.48/−1.37 pp，在 Reddit-S 为 +0.23/+0.30 pp；R-M1 分别为 Movies −0.11/+1.73、Grocery +0.14/−0.38、Reddit-S +0.12/+0.22 pp。表现混合，且初始化、softmax 与计算修复同时变化，不能归因于单一修复。
- **B1 强对照**：S0 相比重新训练的 M0/S2，在三图 Acc/F1 都更高；S1 只在 Movies 高于 S0，三图等权均值 S1−S0 为 −0.21/−0.27 pp。S0/S1 仍是更轻的骨干基线。
- **V/F 对 M0 的描述性增益**：S3−S2 三图等权均值为 +0.33 Acc/+0.40 F1 pp；S4−S2 为 +0.07/+0.85 pp。S5−S2 为 +0.20/+0.24 pp，但按图变化不一致。三种方案均未超过 B1 的 S0/S1 整体水平；模型分别选出的 LR/WD 不同，因此这些差值是所选训练配方的比较。
- **组合交互**：确认阶段 `S5−S3−S4+S2` 的三图等权均值为 −0.20 Acc/−1.01 F1 pp；单个图和 seed 也有变化。seed72 的相同配置交互单独列在后文，仅作参考，不能与确认均值混合。当前不支持稳定的正向组合增益。
- **泛化和成本**：训练与验证之间仍有明显差距，Grocery 尤其接近训练集饱和而验证明显较低；本轮结果不能判定它由共享 φ、竞争路由、F/V 设计还是其它优化因素导致。S2 的中位 step 时间约为 120–136 ms，而 S0 约为 32–47 ms；S5 增加相对 S2 的参数与诊断显存，但没有稳定超过 B1 的验证表现。
- **故障与解释边界**：216 个正式训练单元和 6 个 smoke 均成功；唯一审查修正是对冻结自审脚本的 float32 Acc 容差处理，详见 `review.md` 与 `audit_precision_correction.json`。权重、范数及同头屏蔽结果只说明冻结计算，不是因果效用或真实语义角色证据。三个确认 seed 只作描述性比较，没有显著性结论。

## 成本与结构解释

active backbone 参数不含 task head；active task-head 参数单列。F-off 的统一768维主头最后128列是固定零 padding，其权重数量单独记作 inactive；它不是容量配平。Typed V 相对对应 M0 V-off 的 backbone 增加16,384个参数；F增加65,664个参数。参数预算不代表计算相同。训练 step 计时只覆盖 forward/loss/backward/clip/optimizer.step；全程 wall time含 train/validation、定期诊断与checkpoint。普通峰值显存与诊断峰值分别记录。

V在本实现中只加入模态类型与 same/cross 模态关系条件的公共 value 内容变换；原 Q/K/R_attention、π、α与NULL语义保持。same/cross不指真实KG关系类型。F是差分非线性 residual 适配，不是 RoleMAG 原样复现。S3/S4相对S2隔离各自开关；S1控制一般融合的基线收益。S5交互量受LR/WD各自选择影响，只能解释为已选训练配方的描述性交互。

权重、NULL、范数、梯度和屏蔽变化仅描述此冻结计算系统，不证明真实语义角色、因果效用或信息占比。是否受过拟合、共享φ、竞争gate或优化因素影响，本轮没有因果结论。结果若有seed分歧或接近，应按逐seed表阅读；不会据此增加网格或追加模块。
